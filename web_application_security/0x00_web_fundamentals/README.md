# 0x00 Web Fundamentals

## Web Application Security Module

This project covers foundational web application security concepts and hands-on exploitation of common vulnerabilities.

## Learning Objectives

- How the Web works
- Web 1.0 vs Web 2.0 vs Web 3.0
- Progressive Web Applications (PWA)
- Frontend/Backend communication
- Stateful vs Stateless applications
- Structured vs Unstructured data
- Web Application Security Risks
- Bug Bounty Programs

## Requirements

- Kali Linux 2023.3
- curl
- sqlmap
- Firefox browser
- OpenVPN or Sandbox access
